# nDPI Traffic Fingerprinting
This directory contains the specifications, reference implementations, and metadata resources for nDPI's passive traffic fingerprinting engine. 

Contrary to standalone mechanisms that suffer from high false-positive rates, [nDPI](https://www.ntop.org/products/deep-packet-inspection/ndpi/) utilizes a unified multi-layer approach combining Layer 4 (Transport/OS) and Layer 7 (Application/Encryption) behaviors to create highly accurate client and server identifiers.



## Contributing & Feedback

The specification is an active draft. We highly welcome community contributions, including:
*   Submission of test vectors from novel hardware stacks, IoT devices, or obscure operating systems.
*   Feedback on the ABNF grammar and serialization logic.
*   Independent utility tool implementations.
